# Layer configuration

Settings BitBake reads to load the layer and its machines, explained in the
[configuration reference](../docs/source/user/CONFIGURATION.md).

## Folders

- [machine/](machine/README.md) — Holds one configuration file per supported board.

## Files

- [README.md](README.md) — Lists the layer configuration.
- [layer.conf](layer.conf) — Registers the layer, its recipes, and its dependencies.

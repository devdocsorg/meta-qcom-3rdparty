# Layer configuration

BitBake reads these files to load the layer and its machines. The
[configuration reference](../docs/source/user/CONFIGURATION.md) explains each setting.

## Folders

- [machine/](machine/README.md) — Holds one configuration file per supported board.

## Files

- [layer.conf](layer.conf) — Registers the layer, its recipes, its dependencies, and its supported release series with BitBake.
- [README.md](README.md) — Describes the layer configuration.

# Layer configuration

BitBake configuration for the layer and its machines. The
[configuration reference](../docs/source/user/CONFIGURATION.md) documents each setting.

## Folders

- [machine/](machine/README.md) — Holds one configuration file per supported board.

## Files

- [README.md](README.md) — Indexes the layer configuration.
- [layer.conf](layer.conf) — Registers the layer, its recipes, dependencies, and supported Yocto Project release.

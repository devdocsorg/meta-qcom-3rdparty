# Layer configuration

BitBake reads these files to register the layer and its machines. The
[configuration reference](../docs/source/user/CONFIGURATION.md) explains each
setting.

## Folders

- [machine/](machine/README.md) — Contains one configuration file per supported board.

## Files

- [README.md](README.md) — Describes this folder and indexes its contents.
- [layer.conf](layer.conf) — Registers the layer, its recipe paths, dependencies, and compatible Yocto Project series.

# Layer configuration

BitBake reads [layer.conf](layer.conf) to register the layer, and the
[machine/](machine/README.md) folder defines its boards. The
[configuration reference](../docs/source/user/CONFIGURATION.md) explains each setting.

## Folders

- [machine/](machine/README.md) — Defines the boards this layer supports.

## Files

- [README.md](README.md) — Describes this folder and indexes its contents.
- [layer.conf](layer.conf) — Registers the layer's recipes, dependencies, and compatible Yocto Project release.

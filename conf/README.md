# Layer configuration

The configuration [BitBake](https://github.com/openembedded/bitbake) reads to use this layer and its machines.

## Folders

- [machine/](machine/README.md) — Holds one configuration file per supported board.

## Files

- [README.md](README.md) — Lists the layer configuration.
- [layer.conf](layer.conf) — Registers the layer, its recipes, dependencies, and compatible release series, as the [configuration reference](../docs/source/user/CONFIGURATION.md#layer) describes.

# Machines

One configuration file per supported board; the file name is the `MACHINE`
value. The [configuration reference](../../docs/source/user/CONFIGURATION.md#machines)
explains each setting.

## Files

- [README.md](README.md) — Lists the supported machines.
- [radxa-dragon-q6a.conf](radxa-dragon-q6a.conf) — Radxa Dragon Q6A (QCS6490), booting from Radxa's SPI NOR firmware and producing an EFI disk image.
- [rubikpi3.conf](rubikpi3.conf) — Thundercomm RUBIK Pi 3 (QCS6490), with boot firmware, partitions, and CDT packaged for flashing.

# Supported machines

One configuration per board. Set `MACHINE` to the file name without `.conf`,
or use the board's kas file in [ci/](../../ci/README.md). The
[configuration reference](../../docs/source/user/CONFIGURATION.md#machine-configurations) documents the
settings.

## Files

- [README.md](README.md) — Lists the supported machines.
- [radxa-dragon-q6a.conf](radxa-dragon-q6a.conf) — Radxa Dragon Q6A, based on the QCS6490 SoC.
- [rubikpi3.conf](rubikpi3.conf) — Thundercomm RUBIK Pi 3, based on the QCS6490 SoC.

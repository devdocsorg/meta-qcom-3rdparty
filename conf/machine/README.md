# conf/machine

Contains each supported board definition.

See the [configuration reference](../../docs/source/user/CONFIGURATION.md) for settings and precedence.

## Files

- [README.md](README.md) — Introduces this folder and indexes its maintained contents.
- [radxa-dragon-q6a.conf](radxa-dragon-q6a.conf) — Configures the QCS6490 Radxa board with separately managed SPI NOR firmware.
- [rubikpi3.conf](rubikpi3.conf) — Configures the QCS6490 RUBIK Pi board and its boot assets.

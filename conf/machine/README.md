# Supported machines

Set `MACHINE` to a file name without `.conf`, or use its kas file in
[ci/](../../ci/README.md). The
[configuration reference](../../docs/source/user/CONFIGURATION.md#machines)
explains each setting.

## Files

- [README.md](README.md) — Lists the supported machines.
- [rubikpi3.conf](rubikpi3.conf) — Thundercomm RUBIK Pi 3, with the QCS6490 SoC.
- [radxa-dragon-q6a.conf](radxa-dragon-q6a.conf) — Radxa Dragon Q6A, with the QCS6490 SoC.

# machine

Defines the RUBIK Pi 3 and Radxa Dragon Q6A hardware settings.

## Files

- [README.md](README.md) — Describes this folder and indexes its immediate contents.
- [radxa-dragon-q6a.conf](radxa-dragon-q6a.conf) — Configures the Radxa OS disk image while leaving SPI NOR firmware to the vendor.
- [rubikpi3.conf](rubikpi3.conf) — Configures QCS6490 hardware, device tree, firmware, and partition selection.

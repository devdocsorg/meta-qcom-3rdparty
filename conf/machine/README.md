# Machine configurations

Set `MACHINE` to a file name without `.conf` to build for that board. The
[configuration reference](../../docs/source/user/CONFIGURATION.md#machine-configurations)
explains each setting.

## Files

- [README.md](README.md) — Describes this folder and indexes its contents.
- [radxa-dragon-q6a.conf](radxa-dragon-q6a.conf) — Configures the Radxa Dragon Q6A (QCS6490), which boots from Radxa-managed SPI NOR firmware.
- [rubikpi3.conf](rubikpi3.conf) — Configures the Thundercomm RUBIK Pi 3 (QCS6490).

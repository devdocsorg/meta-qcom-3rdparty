# Machine configurations

Each file defines a board that this layer supports; its name without `.conf` is
the `MACHINE` value. The
[configuration reference](../../docs/source/user/CONFIGURATION.md#machines)
explains the settings.

| Machine | Board | SoC |
| --- | --- | --- |
| `rubikpi3` | Thundercomm RUBIK Pi 3 | QCS6490 |
| `radxa-dragon-q6a` | Radxa Dragon Q6A | QCS6490 |

## Files

- [README.md](README.md) — Lists the supported machines.
- [rubikpi3.conf](rubikpi3.conf) — Defines the Thundercomm RUBIK Pi 3.
- [radxa-dragon-q6a.conf](radxa-dragon-q6a.conf) — Defines the Radxa Dragon Q6A.

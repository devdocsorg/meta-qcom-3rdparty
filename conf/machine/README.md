# Machine configurations

Each file defines a board that builds with `MACHINE` set to its name. The
[configuration reference](../../docs/source/user/CONFIGURATION.md#machines)
explains the settings.

## Files

- [README.md](README.md) — Lists the supported boards.
- [radxa-dragon-q6a.conf](radxa-dragon-q6a.conf) — Radxa Dragon Q6A (QCS6490), booting a UEFI disk image from firmware in SPI NOR.
- [rubikpi3.conf](rubikpi3.conf) — Thundercomm RUBIK Pi 3 (QCS6490), flashed with its boot firmware and partition tables.

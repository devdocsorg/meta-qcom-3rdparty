# Contributing

Follow the [contributor guide](docs/source/contributing/CONTRIBUTING.md) and the
[development environment walkthrough](docs/source/contributing/DEVELOPMENT.md).
Send product changes to [qualcomm-linux/meta-qcom-3rdparty](https://github.com/qualcomm-linux/meta-qcom-3rdparty/compare/main...main?expand=1&template=change.md),
usually against `main`; see [branch guidance](BRANCHES.md) for release work.
The DevDocs fork hosts documentation review work and does not replace upstream ownership.

Use the [change template](.github/PULL_REQUEST_TEMPLATE/change.md), describe checks
actually run, and sign off every commit. The [Code of Conduct](CODE_OF_CONDUCT.md)
and [private security reporting route](SECURITY.md) apply.

Documentation follows the [canonical repository specification](https://github.com/devdocsorg/qli2-example-repo/blob/main/SPECIFICATION.md).

# Contributing to meta-qcom-3rdparty

The [contribution guide](docs/source/contributing/CONTRIBUTING.md) owns the upstream
process, BSP scope, and board integration examples. Start with the concrete
[development environment](docs/source/contributing/DEVELOPMENT.md).

Submit project changes to [qualcomm-linux/meta-qcom-3rdparty](https://github.com/qualcomm-linux/meta-qcom-3rdparty/compare/main...HEAD?expand=1&template=pr_template.md).
The `devdocsorg` fork's documentation branch is a review checkout; it does not
change the upstream contribution destination. The local
[PR template](.github/PULL_REQUEST_TEMPLATE/pr_template.md) also supports fork review.

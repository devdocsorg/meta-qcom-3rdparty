# Board support recipes

Recipes for board firmware and the packagegroups that machine configurations
pull into images.

## Folders

- [firmware-boot/](firmware-boot/README.md) — Contains boot firmware recipes for boards that [meta-qcom](https://github.com/qualcomm-linux/meta-qcom) does not cover.
- [packagegroups/](packagegroups/README.md) — Contains the per-board firmware packagegroups.

## Files

- [README.md](README.md) — Describes the board support recipes.

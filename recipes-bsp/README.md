# Board support recipes

Firmware and package group recipes for the supported boards.

## Folders

- [firmware-boot/](firmware-boot/README.md) — Holds the boot firmware recipe for boards whose firmware [`meta-qcom`](https://github.com/qualcomm-linux/meta-qcom) does not provide.
- [packagegroups/](packagegroups/README.md) — Holds one firmware package group recipe per board.

## Files

- [README.md](README.md) — Describes the board support recipes.

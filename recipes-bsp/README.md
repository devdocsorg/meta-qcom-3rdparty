# Board support recipes

Recipes for board firmware and packagegroups. The
[contribution guide](../docs/source/contributing/CONTRIBUTING.md#6--machine-example--thundercomm-rubik-pi-3)
explains how they fit a new board.

## Folders

- [firmware-boot/](firmware-boot/README.md) — Holds the boot firmware recipes.
- [packagegroups/](packagegroups/README.md) — Holds the machine packagegroups.

## Files

- [README.md](README.md) — Indexes the board support recipes.

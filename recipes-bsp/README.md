# Board support recipes

Firmware and package selection for the boards in [conf/machine/](../conf/machine/README.md).

## Folders

- [firmware-boot/](firmware-boot/README.md) — Holds boot firmware recipes for boards that the recipes in [meta-qcom](https://github.com/qualcomm-linux/meta-qcom) do not cover.
- [packagegroups/](packagegroups/README.md) — Holds one packagegroup per board with its firmware packages.

## Files

- [README.md](README.md) — Describes the board support recipes.

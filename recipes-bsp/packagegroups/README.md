# Packagegroups

Machine packagegroups that the machine configurations add to every image.

## Files

- [README.md](README.md) — Describes this folder and indexes its contents.
- [packagegroup-radxa-dragon-q6a.bb](packagegroup-radxa-dragon-q6a.bb) — Groups the Radxa Dragon Q6A firmware and, separately, its Hexagon DSP binaries.
- [packagegroup-rubikpi3.bb](packagegroup-rubikpi3.bb) — Groups the Thundercomm RUBIK Pi 3 firmware.

# Package groups

The machine definitions recommend these groups so images include each board's
firmware.

## Files

- [README.md](README.md) — Lists the package groups.
- [packagegroup-radxa-dragon-q6a.bb](packagegroup-radxa-dragon-q6a.bb) — Groups the Radxa Dragon Q6A firmware, with the Hexagon DSP binaries in a separate package.
- [packagegroup-rubikpi3.bb](packagegroup-rubikpi3.bb) — Groups the RUBIK Pi 3 firmware.

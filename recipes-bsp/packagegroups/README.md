# Board packagegroups

Machine configurations recommend these packagegroups so that images include each
board's firmware.

## Files

- [README.md](README.md) — Describes the board packagegroups.
- [packagegroup-rubikpi3.bb](packagegroup-rubikpi3.bb) — Lists the RUBIK Pi 3 firmware packages.
- [packagegroup-radxa-dragon-q6a.bb](packagegroup-radxa-dragon-q6a.bb) — Lists the Radxa Dragon Q6A firmware and Hexagon DSP binary packages.

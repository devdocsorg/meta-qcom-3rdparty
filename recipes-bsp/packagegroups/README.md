# Package groups

Each machine adds its package groups to every image through
`MACHINE_ESSENTIAL_EXTRA_RRECOMMENDS`.

## Files

- [packagegroup-radxa-dragon-q6a.bb](packagegroup-radxa-dragon-q6a.bb) — Groups the Radxa Dragon Q6A firmware and, separately, its DSP binaries.
- [packagegroup-rubikpi3.bb](packagegroup-rubikpi3.bb) — Groups the RUBIK Pi 3 firmware.
- [README.md](README.md) — Describes the package group recipes.

# Packagegroups

Machine-specific packagegroups that pull firmware into images.

## Files

- [README.md](README.md) — Lists the packagegroups.
- [packagegroup-radxa-dragon-q6a.bb](packagegroup-radxa-dragon-q6a.bb) — Firmware for the Radxa Dragon Q6A, with its Hexagon DSP binaries in a separate package.
- [packagegroup-rubikpi3.bb](packagegroup-rubikpi3.bb) — Firmware for the RUBIK Pi 3.

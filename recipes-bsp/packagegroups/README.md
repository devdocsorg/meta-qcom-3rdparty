# Board packagegroups

Firmware packages each machine recommends into its images.

## Files

- [README.md](README.md) — Lists the board packagegroups.
- [packagegroup-rubikpi3.bb](packagegroup-rubikpi3.bb) — RUBIK Pi 3 GPU, video, audio, compute, and serial-engine firmware.
- [packagegroup-radxa-dragon-q6a.bb](packagegroup-radxa-dragon-q6a.bb) — Radxa Dragon Q6A firmware, with the Hexagon DSP binaries in a separate package.

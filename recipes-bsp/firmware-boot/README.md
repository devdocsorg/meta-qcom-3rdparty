# Boot firmware

Recipes that deploy board boot firmware for the `qcomflash` package.

## Files

- [README.md](README.md) — Lists the boot firmware recipes.
- [firmware-qcom-boot-rubikpi3_20260915.bb](firmware-qcom-boot-rubikpi3_20260915.bb) — Fetches the RUBIK Pi 3 boot firmware and CDT from the vendor's [`rubikpi-ai/boot-assets`](https://github.com/rubikpi-ai/boot-assets) repository and deploys them.

# Boot firmware recipes

Recipes that deploy a board's boot binaries for the flashable package. The
[function reference](../../docs/source/contributing/README.md#function-reference)
documents their tasks.

## Files

- [README.md](README.md) — Describes the boot firmware recipes.
- [firmware-qcom-boot-rubikpi3_20260915.bb](firmware-qcom-boot-rubikpi3_20260915.bb) — Fetches the RUBIK Pi 3 boot binaries and CDT from the vendor and deploys them.

# Boot firmware

Recipes for boot binaries that [meta-qcom](https://github.com/qualcomm-linux/meta-qcom)
does not provide.

## Files

- [README.md](README.md) — Lists the boot firmware recipes.
- [firmware-qcom-boot-rubikpi3_20260621.bb](firmware-qcom-boot-rubikpi3_20260621.bb) — Fetches the RUBIK Pi 3 boot binaries and CDT from [rubikpi-ai/boot-assets](https://github.com/rubikpi-ai/boot-assets) and deploys them for the flashable package.

# Boot firmware recipes

Recipes that deploy board boot firmware for the `qcomflash` package, for boards
that need binaries [meta-qcom](https://github.com/qualcomm-linux/meta-qcom) does not provide.

## Files

- [README.md](README.md) — Indexes the boot firmware recipes.
- [firmware-qcom-boot-rubikpi3_20260915.bb](firmware-qcom-boot-rubikpi3_20260915.bb) — Deploys the RUBIK Pi 3 boot binaries and CDT from the vendor's [boot-assets](https://github.com/rubikpi-ai/boot-assets) repository.

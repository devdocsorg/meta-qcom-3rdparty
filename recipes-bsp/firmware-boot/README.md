# Boot firmware recipes

These recipes deploy vendor boot binaries that the `qcomflash` image type
packages; the [function reference](../../docs/source/contributing/README.md#function-reference)
documents their tasks.

## Files

- [README.md](README.md) — Describes the boot firmware recipes.
- [firmware-qcom-boot-rubikpi3_20260621.bb](firmware-qcom-boot-rubikpi3_20260621.bb) — Fetches and deploys the RUBIK Pi 3 boot firmware and CDT.

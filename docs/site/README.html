meta-qcom-3rdparty Documentation¶

Use the contributor guides to build or extend the layer, and the user guides to understand its configuration.

Folders¶

  • .templates/: Supplies the generated local-browser entry point.

  • contributing/: Contribution guidelines, the usage tutorial, agent instructions, and generated function reference.

  • user/: User-facing configuration documentation.

Files¶

  • Makefile: Provides the shared local and CI setup, build, and reproducibility commands.

  • README.md: Introduces the documentation and lists its contents.

  • conf.py: Extracts function comments with shdoc and configures Sphinx.

  • requirements.txt: Pins the Python documentation dependencies.

  • requirements.lock — Locks direct and transitive documentation dependencies for reproducible builds.

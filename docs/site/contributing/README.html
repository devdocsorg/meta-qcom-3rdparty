Contributor guides¶

Follow the contribution procedure, set up the development environment, and retain the agent workflow. Function reference pages are extracted from native comments during each build. The shell pages include internal helpers; the Python page uses Sphinx autodoc.

Files¶

  • CONTRIBUTING.md — Explains contribution requirements and links the development environment.

  • DEVELOPMENT.md — Walks through checkout, tools, configuration, and required checks.

  • README.md — Introduces this folder and indexes its immediate contents.

doc_reference.bitbake_functions(path: Path) → list[tuple[str, int]]¶

Inventory BitBake task definitions through its native parse-only statement API.

Parameters:

path – Recipe, append, class, include, or configuration path.

Returns:

Shell task names and source offsets; inherited tasks are excluded.

Raises:

  • ValueError – For embedded Python or shell forms requiring extractor setup.

  • RuntimeError – If the pinned BitBake parser is missing.

Example: bitbake_functions(ROOT / 'recipes-bsp/firmware-boot/firmware-qcom-boot-rubikpi3_20260621.bb'). No statements are evaluated, no includes loaded, and no tasks run.

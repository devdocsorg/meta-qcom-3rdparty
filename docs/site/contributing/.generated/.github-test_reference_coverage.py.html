.github/test_reference_coverage.py¶

Find every function definition and check its native reference.

Usage: test_reference_coverage.py generate | check

docs/source/conf.py runs “generate” before Sphinx reads its sources: it fails on source formats without a configured extractor, on functions without a configured renderer, and on undocumented functions, then writes one reference page per source file to docs/source/contributing/.generated/. The Makefile runs “check” after the HTML build: it fails when a function has no rendered reference entry.

Functions are found in tracked and staged files with parsers, independently of the renderers; nothing is executed. Python’s ast module reads Python files, and tree-sitter-bash reads shell scripts, workflow run steps, and Makefile recipes. BitBake’s own statement parser, which the Makefile’s setup installs, splits BitBake metadata and kas configuration snippets into shell and Python definitions without evaluating them; shell task bodies then go to tree-sitter-bash to find functions nested in them. Adapting a repository means adding its source formats to discover() and a renderer for each language that defines functions to RENDERERS.

class test_reference_coverage.Shdoc¶

Render shell functions with the pinned shdoc, which the Makefile’s setup installs.

shdoc reads the @description, @arg or @noargs, @exitcode, and @example annotations in the comment block above each definition, and runs on GNU Awk.

test_reference_coverage.bitbake_functions(path, where, text)¶

List the functions defined in BitBake metadata.

BitBake’s statement parser splits the text into statements without evaluating them. Shell tasks keep the comment block directly above their definition; functions nested in a shell task, and BitBake Python functions, are reported under their own language so that the build names them instead of skipping them.

Parameters:

  • path (str) – Source path, used in reports.

  • where (str) – Location inside the file, such as a kas snippet, or “”.

  • text (str) – BitBake metadata.

Returns:

One entry per function with its language, name, line, and comment block.

Return type:

list[dict]

Raises:

ValueError – BitBake’s parser or the shell parser cannot read the text.

Example

bitbake_functions("recipes-bsp/a/a.bb", "", "do_deploy() {\n    :\n}\n") finds do_deploy.

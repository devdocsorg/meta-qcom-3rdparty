native_reference.shell_functions(text: str) → list[tuple[str, int]][source]¶

Find every shell function using bashlex, including nested definitions.

Parameters:

text (str) – Shell source text; never executed.

Returns:

Function names and zero-based declaration offsets.

Return type:

list[tuple[str, int]]

Raises:

ValueError – The parser encounters unsupported shell syntax.

Example:

shell_functions('check() { test -d "$1"; }')

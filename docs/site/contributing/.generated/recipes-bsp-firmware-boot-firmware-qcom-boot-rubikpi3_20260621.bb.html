Functions¶

do_deploy¶

Install the boot binaries and the CDT where the qcomflash image class collects them.

Example¶

bitbake firmware-qcom-boot-rubikpi3 -c deploy

Function has no arguments.

Exit codes¶

  • 0: The ELF, MBN, FV, and IMG boot files and RubikPi3_CDT.bin are in ${DEPLOYDIR}/${QCOM_BOOT_IMG_SUBDIR}.

  • 1: A file could not be installed, for example when RubikPi3_CDT.bin is missing; the task fails.

do_deploy¶

Deploy boot firmware and the board-specific CDT. BitBake supplies S and DEPLOYDIR as directory paths and QCOM_BOOT_IMG_SUBDIR as a relative subdirectory string.

Example¶

bitbake -c deploy firmware-qcom-boot-rubikpi3

Function has no arguments.

Exit codes¶

  • 0: The firmware and CDT are installed in the deployment directory.

  • 1: A required directory or file could not be installed.

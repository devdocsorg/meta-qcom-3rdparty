Functions¶

_is_dir¶

Check that a path names an existing directory, exiting the script when it does not.

Example¶

_is_dir "$WORK_DIR"

Arguments¶

  • $1 (string): Directory path to check, such as REPO_DIR or WORK_DIR.

Exit codes¶

  • 0: The path is a directory.

  • 1: The path is not a directory; the whole script exits with this status.

Output on stdout¶

  • An error message naming the path when it is not a directory.

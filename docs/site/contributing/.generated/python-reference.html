Python documentation tools¶

Native docstrings are rendered by Sphinx autodoc.

.github/reference.py¶

Inventory definitions independently, then generate and check native references.

Shell and BitBake task comments are rendered by pinned shdoc. Python modules use Sphinx autodoc; AST parsing never imports product code or executes build tasks.

reference.check_rendered(root: Path, site: Path) → dict[str, list[str]]¶

Require actual native-domain HTML entries for every discovered function.

Parameters:

  • root – Repository root Path, for example Path.cwd().

  • site – Generated site Path, for example root / 'docs/site'.

Returns:

Source-path strings mapped to documented function-name lists.

Raises:

ValueError – A rendered reference entry is missing or documentation is invalid.

Example: check_rendered(Path.cwd(), Path('docs/site')) validates the built reference.

reference.generate(root: Path) → None¶

Generate native-reference source pages without executing product functions.

Parameters:

root – Repository root Path; generate(Path.cwd()) is used by Sphinx.

Returns:

None; writes ignored intermediate Markdown under the contributor area.

Raises:

  • ValueError – Inventory or extraction misses documented definitions.

  • subprocess.CalledProcessError – Pinned shdoc fails.

Example: generate(Path.cwd()) creates the shell task and Python reference pages.

reference.inventory(root: Path) → dict[Path, list[str]]¶

Validate native comments and discover all shell, BitBake, and Python definitions.

Parameters:

root – Repository root Path, for example Path.cwd().

Returns:

Mapping from relative source Path to discovered qualified function names.

Raises:

ValueError – Documentation is missing or a definition needs extractor support.

Example: inventory(Path.cwd())[Path('ci/yocto-buildstats.sh')] is ['_is_dir'].

reference.shell_functions(text: str) → list[tuple[str, int]]¶

Discover shell function names and positions with bashlex’s independent AST.

Parameters:

text – Shell source string, such as 'f() { :; }'.

Returns:

List of (name string, character offset integer) pairs, including helpers.

Raises:

ValueError – Shell syntax cannot be parsed; update parser support explicitly.

Example: shell_functions('f() { :; }') returns [('f', 0)].

reference.source_files(root: Path) → list[Path]¶

Return maintained source paths using Git’s tracked and unignored inventory.

Parameters:

root – Repository root (Path), for example Path.cwd().

Returns:

Sorted list of repository-relative Paths, excluding generated HTML.

Raises:

subprocess.CalledProcessError – Git cannot enumerate the repository.

Example: source_files(Path.cwd()) includes Path('ci/yocto-check-layer.sh').

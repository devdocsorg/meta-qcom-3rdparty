### do_deploy

Install RUBIK Pi boot binaries and its CDT into the deploy staging directory.

#### Example

```bash
  bitbake firmware-qcom-boot-rubikpi3 -c deploy
@exitcode 0 Deployment completes; there is no return value on stdout.
@exitcode 1 Installation fails when source assets are missing or staging is unwritable.
@stderr Diagnostics from install or find when deployment fails.
Uses BitBake string paths S, DEPLOYDIR, and QCOM_BOOT_IMG_SUBDIR.
```

_Function has no arguments._

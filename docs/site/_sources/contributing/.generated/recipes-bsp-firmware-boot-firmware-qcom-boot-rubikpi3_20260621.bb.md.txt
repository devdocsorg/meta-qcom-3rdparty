### do_deploy

Stage RUBIK Pi 3 firmware and CDT for the image packaging tasks.
Reads string S (unpacked source directory), DEPLOYDIR (deploy staging),
and QCOM_BOOT_IMG_SUBDIR (board directory, rubikpi3) from BitBake.

#### Example

```bash
bitbake firmware-qcom-boot-rubikpi3 -c deploy
```

_Function has no arguments._

#### Exit codes

* **0**: Firmware files were installed successfully.
* **1**: A required file or output directory could not be read or written.

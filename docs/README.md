# Documentation

Open [site/index.html](site/index.html) directly in a browser to read the
generated site; no HTTP server or documentation tools are needed. The project
entry point remains the root [README](../README.md).

Edit the [source](source/README.md), follow the
[development setup](source/contributing/DEVELOPMENT.md) to rebuild and check the
site, and commit the source and regenerated site together. Generated
[third-party asset notices](site/THIRD_PARTY_LICENSES.txt) keep the licences of
the Sphinx assets bundled with the site.

## Folders

- [source/](source/README.md) — Contains the authoritative guides and the documentation build configuration.
- [site/](site/index.html) — Contains the generated, locally browsable HTML site and its assets.

## Files

- [README.md](README.md) — Points to the documentation source, the built site, and the build walkthrough.

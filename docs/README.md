# Documentation

Authored guides and Sphinx configuration live under `source`. Open
[the generated site](site/index.html) directly in a browser; it works when copied
elsewhere without a server or network connection. Contributions follow
[the development walkthrough](source/contributing/DEVELOPMENT.md).

## Folders

- [site](site/index.html) — Provides the generated website entry point for direct-file browsing.
- [source](source/README.md) — Owns the documentation prose and reproducible Sphinx build configuration.

## Files

- [README.md](README.md) — Introduces this folder and indexes its maintained contents.

# Documentation

Open [site/index.html](site/index.html) directly in a browser to read the
generated site; it needs no HTTP server or network access. Edit the
[source](source/README.md) and rebuild the site as described in
[development setup](source/contributing/DEVELOPMENT.md). Commit the sources
and the regenerated site together.

The site's bundled JavaScript keeps its upstream licence headers, collected in
[site/THIRD_PARTY_LICENSES.txt](site/THIRD_PARTY_LICENSES.txt).

## Folders

- [source/](source/README.md) — Contains the authored guides and the documentation build configuration.
- [site/](site/index.html) — Contains the generated, locally browsable HTML site.

## Files

- [README.md](README.md) — Points to the documentation source, the built site, and the build walkthrough.

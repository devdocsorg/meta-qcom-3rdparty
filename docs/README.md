# Documentation

Open [site/index.html](site/index.html) directly in a browser to read the generated
site. No HTTP server or documentation tools are needed to read it.

Edit the [source](source/README.md), follow the
[development setup](source/contributing/DEVELOPMENT.md) to rebuild it, and commit
the source and regenerated site together.

Generated [third-party asset notices](site/THIRD_PARTY_LICENSES.txt) preserve the
licences supplied by the locked documentation packages.

## Folders

- [source/](source/README.md) — Contains the authoritative guides and the documentation build configuration.
- [site/](site/index.html) — Contains the generated, locally browsable HTML site and its assets.

## Files

- [README.md](README.md) — Points to the documentation source, the built site, and the build walkthrough.

# Dynamic layers

Recipes and appends that [BitBake](https://github.com/openembedded/bitbake) uses only when another layer is present, as
`BBFILES_DYNAMIC` in [`conf/layer.conf`](../conf/layer.conf) selects.

## Folders

- [qcom-distro/](qcom-distro/README.md) — Applies when [`meta-qcom-distro`](https://github.com/qualcomm-linux/meta-qcom-distro) is in the build.

## Files

- [README.md](README.md) — Explains when the dynamic layers apply.

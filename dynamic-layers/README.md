# Dynamic layers

Recipes and appends here apply only when another layer is in the build;
`BBFILES_DYNAMIC` in [conf/layer.conf](../conf/layer.conf) selects them.

## Folders

- [qcom-distro/](qcom-distro/README.md) — Holds appends that apply when the `qcom-distro` layer from [`meta-qcom-distro`](https://github.com/qualcomm-linux/meta-qcom-distro) is present.

## Files

- [README.md](README.md) — Explains when the dynamic layers apply.

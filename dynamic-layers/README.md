# Dynamic layers

Each folder is named after a layer collection; BitBake parses it only when that
layer is in the build, as `BBFILES_DYNAMIC` in
[conf/layer.conf](../conf/layer.conf) sets.

## Folders

- [qcom-distro/](qcom-distro/README.md) — Contains additions for builds that include meta-qcom-distro.

## Files

- [README.md](README.md) — Describes the dynamic layers.

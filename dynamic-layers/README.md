# Dynamic layers

Metadata that BitBake reads only when the named layer collection is in the
build, through `BBFILES_DYNAMIC` in [layer.conf](../conf/layer.conf).

## Folders

- [qcom-distro/](qcom-distro/README.md) — Applies when [meta-qcom-distro](https://github.com/qualcomm-linux/meta-qcom-distro) is in the build.

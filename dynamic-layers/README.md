# Dynamic layers

Files that BitBake adds only when another layer is in the build, through
`BBFILES_DYNAMIC` in [conf/layer.conf](../conf/layer.conf).

## Folders

- [qcom-distro/](qcom-distro/README.md) — Applies when [meta-qcom-distro](https://github.com/qualcomm-linux/meta-qcom-distro) is in the build.

## Files

- [README.md](README.md) — Indexes the dynamic layers.

# Dynamic layers

BitBake loads a folder here only when the layer it is named after is present,
through `BBFILES_DYNAMIC` in [conf/layer.conf](../conf/layer.conf).

## Folders

- [qcom-distro/](qcom-distro/README.md) — Contains appends applied when [meta-qcom-distro](https://github.com/qualcomm-linux/meta-qcom-distro) is present.

## Files

- [README.md](README.md) — Describes the dynamic layers.
